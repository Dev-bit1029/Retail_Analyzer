# 🛒 RETAIL SALES DATA ANALYZER

## 📌 Sub-title
A Python-based data analysis project used to explore, clean, analyze, and visualize retail sales data using Pandas, Matplotlib, and Seaborn.

---

## 1. Features

- **Explore Data**
  - Display Top 5 Records.
  - Display Last 5 Records.
  - Show Dataset Information.
  - Check Data Types.

- **Clear Data**
  - Check Missing Values.
  - Delete Missing Data.
  - Fill Missing Data with 0.
  - Display Duplicate Records.

- **Perform Data Analysis**
  - Calculate Total Sales.
  - Calculate Average Sales.
  - Find Maximum Sales.
  - Find Minimum Sales.
  - Calculate Total Quantity Sold.
  - Find the Most Popular Product.

- **Data Visualization**
  - Bar Chart.
  - Pie Chart.
  - Line Chart.
  - Scatter Chart.
  - Histogram Chart.

- **Data Analysis Report**
  - Generate a Complete Retail Sales Summary.
  - Display Total Records and Columns.
  - Display Missing Values.
  - Display Duplicate Records.

## 5. Installation

Follow these steps to install and run the project.

**Step 1: Install Python**

Download and install Python from:

https://www.python.org/downloads/

**Step 2: Install Required Libraries**

Open your terminal or command prompt and execute:

```bash
pip install pandas matplotlib seaborn
```

**Step 3: Download or Clone the Project**

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

**Step 4: Open the Project Folder**

```bash
cd Retail-Sales-Data-Analyzer
```

**Step 5: Run the Python Program**

```bash
python main.py
```

**Step 6: Enter CSV File Name**

```text
retail_sales.csv
```
